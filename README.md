# eStudent

Aplicație web pentru evidența studenților: backend NestJS (`api/`) și frontend React + Vite (`web/`).

## Pornire

Primul terminal (backend):

    cd api
    npm install
    npm run start:dev

Al doilea terminal (frontend):

    cd web
    npm install
    npm run dev

Aplicația: http://localhost:5173 · API: http://localhost:3000/api/health
